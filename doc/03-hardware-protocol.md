# 03. EC 与 ACPI 硬件控制协议说明

本文档总结了 `rmechrevo` 针对同方 / Uniwill `INOU0000` 模具（主测机型：**机械革命 蛟龙 16 Pro 2025**，主板 `JIAOLONG Series-X6xR55xK-B2`、BIOS `N.1.19MRO20`、EC `1.31`）在 `src/ec/registers.rs` 及各硬件模块中实现的底层协议。

## 1. ACPI / EC 通信通道

主板 BIOS 在 ACPI 命名空间暴露了 `\_SB.INOU` 设备，通过 `acpi_call` 内核模块（`/proc/acpi/call`）读写 16 位 EC RAM 偏移地址：

- **读单字节**：`\_SB.INOU.ECRR 0x<ADDR>`
- **写单字节**：`\_SB.INOU.ECRW 0x<ADDR> 0x<VAL>`

所有读写统一封装在 `src/ec/mod.rs`，由进程内互斥锁 `EC_LOCK` 串行化访问。

## 2. 核心寄存器映射总表

| 寄存器 | 名称（`src/ec/registers.rs`） | 用途 |
|---|---|---|
| `0x0741` | `ADDR_AP_OEM` | 控制台在线标志：`0x01` 软件接管，`0x00` 还原 EC 自主托管 |
| `0x0751` | `ADDR_MAFAN_CONTROL` | 主性能模式控制：`0x10` 狂暴、`0x00` 均衡、`0x40` 办公、`0x80` 用户风扇曲线 |
| `0x07AB` | `ADDR_BRIGHTNESS_MODE` | 复合寄存器：高 3 位键盘亮度档位（`0x20/0x40/0x60/0x80`），低 5 位性能模式索引（`0x02` 狂暴 / `0x00` 均衡 / `0x01` 办公） |
| `0x0727` | `ADDR_CUSTOM_MODE` | 自定义模式开关：`0x40` 启用（机身灯变白，解锁功耗墙），`0x00` 关闭 |
| `0x0728` | `ADDR_SILENT_TURBO` | 狂暴子模式：`0x01` 静音狂暴（限速降噪），`0x00` 满血狂暴 |
| `0x077E` | `ADDR_CUSTOM_POWER_SEQ` | CPU 自定义功耗握手序列端口：`55 AA 00 00 D8 <PL1> <PL2> <PL4>` |
| `0x0767` | `ADDR_TRIGGER_BYTE` | 复合触发寄存器：bit 0 (`0x01`) Win 键锁翻转、bit 2 (`0x04`) 暴风强冷、bit 5 (`0x20`) RGB 锁存脉冲、bit 7 (`0x80`) 彩虹模式 |
| `0x075D` | `ADDR_TRIGGER_BYTE2` | 辅助触发寄存器：bit 5 (`0x20`) RGB 锁存脉冲 |
| `0x0768` | `ADDR_STATUS_BYTE` | 辅助状态寄存器：bit 0 Win 键锁定真实状态（`1` 锁定 / `0` 可用） |
| `0x0766` | `ADDR_SUPPORT_BYTE2` | 硬件支持标志：bit 2 (`0x04`) 单区 RGB 键盘支持位 |
| `0x078C` | `ADDR_SINGLEKBL_ENABLE` | 单区键盘电源与亮度：bit 1 (`0x02`) 硬件断电禁用位；高 4 位亮度档位（`0x30/0x50/0x70/0x90`） |
| `0x0769`~`0x076B` | `ADDR_RGB_R/G/B` | 单区键盘单色常亮 PWM 分量（范围 `0~50`，经原厂 29 组偏色校准表映射） |
| `0x07C5` | `ADDR_EFFECT_SUB` | 单区键盘呼吸子通道（低 3 位：`0` 关闭、`1` 红、`2` 绿、`3` 蓝、`4` 白） |
| `0x074E` | `ADDR_FN_LOCK` | Fn 键翻转：bit 4 (`0x10`) |
| `0x07A6` | `ADDR_TOUCHPAD` | 触控板禁用标志：bit 6 (`0x40`) |
| `0x074F` / `0x07B9` / `0x07D0` | 电池养护三寄存器 | 模式锁存（`0x01` 60% / `0x02` 80% / `0x00` 100%）、充电上限、复充门限 |
| `0x0464` / `0x0465`, `0x046C` / `0x046B` | 双风扇转速 | 左 CPU 风扇与右 GPU 风扇实时 RPM（大端 16 位） |
| `0x0F20`~`0x0F33`, `0x0F70`~`0x0F83` | RamFan2 曲线表 | 左右双风扇 10 阶梯自定义温控曲线 |

## 3. 四档互斥性能模式

性能模式在底层严格互斥，统一以 `PerformanceMode`（`0` 狂暴 / `1` 均衡 / `2` 办公 / `3` 自定义）作为唯一状态源：

- **切换至狂暴 / 均衡 / 办公时**：先清除自定义模式（`0x0727 = 0x00` 并清空 `0x077E` 功耗序列），再写入 `0x0751` 与 `0x07AB`（低 5 位），**严格保留 `0x07AB` 高 3 位当前键盘亮度状态**，避免切模式导致已关闭的键盘背光重新点亮。
- **切换至自定义模式时**：置 `0x0727 = 0x40`，下发用户配置的 CPU PL1/PL2/PL4 功耗序列、GPU Dynamic Boost / 频率偏移及 RamFan2 双风扇曲线，机身模式灯切换为白光。
- **机身物理按键联动**：`src/hotkeys.rs` 监听 `Uniwill WMI hotkeys` 输入事件，按物理模式键时自动在狂暴/均衡/办公间轮换并同步退清自定义状态，广播到前端界面。

## 4. 单区 RGB 键盘背光协议

`src/rgb.rs` 完整对齐原厂单区键盘（`SingleZone`）硬件协议：

1. **物理关灯**：清 `0x07C5` 低 3 位、清 `0x0767` 彩虹位、置 `0x078C` bit 1 (`0x02`) 硬件断电、清 `0x07AB` 高 3 位与 RGB 通道并发送锁存脉冲。
2. **亮度档位（4 档）**：25% → `(0x30, 0x20)`、50% → `(0x50, 0x40)`、75% → `(0x70, 0x60)`、100% → `(0x90, 0x80)`，调亮度时自动保持当前激活的灯效模式（常亮/彩虹/呼吸）。
3. **常亮模式（Static）**：清 `0x07C5` 低 3 位，将 RGB 经原厂 29 点硬件校准表转换为 `0~50` 级别（如纯白校准为 `(50, 40, 40)` 以抵消绿蓝 LED 偏色），写入 `0x0769`~`0x076B` 并触发 `0x0767` / `0x075D` bit 5 锁存脉冲。
4. **彩虹模式（Rainbow）**：清 `0x07C5` 低 3 位、清 `0x0769`~`0x076B` 为 `0`，触发 `0x0767` bit 7 (`0x80`) + bit 5 脉冲（彩虹为硬件动画，无独立色彩设置）。
5. **呼吸模式（Breathing）**：EC 固件的硬件呼吸模式不读取 `0x0769`~`0x076B`，而是通过 `0x07C5` 低 3 位选择内置的 **4 种固定呼吸颜色**：`1` 烈红、`2` 亮绿、`3` 纯蓝、`4` 纯白。切换呼吸颜色时先清 `0x0767` 彩虹位，必要时复位 `0x07C5` 低 3 位后再写入目标索引。

## 5. 电池养护与显卡 MUX

- **电池养护**（`src/battery.rs`）：同步写入 `0x074F`、`0x07B9`（上限）与 `0x07D0`（复充下限），提供三档预设：
  - 长效养护：上限 60%，复充 50%（`0x074F = 0x01`）
  - 日常平衡：上限 80%，复充 75%（`0x074F = 0x02`）
  - 常规充满：上限 100%，复充 95%（`0x074F = 0x00`）
- **显卡输出拓扑**（`src/gpu_mode.rs`）：通过 ACPI/sysfs 探测当前处于 **独显直连（dGPU Only）** 还是 **混合输出（Hybrid）**，切换 MUX 模式后需重启生效；在混合模式下支持运行时独显供电启停控制，独显直连模式下自动锁定防误切断显示输出。
